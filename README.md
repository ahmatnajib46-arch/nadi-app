# NADI

**Your Personal Management Space**

NADI is a personal management application designed to help manage finances, daily progress, and projects.

## Project Status

Currently in initial development.

## Documentation

- Product Requirements Document: `docs/PRD.md`
- Technical Specification: `docs/TECHNICAL_SPEC.md`
- Implementation Blueprint: `docs/IMPLEMENTATION_BLUEPRINT.md`

## Technology Stack

- React
- Vite
- TypeScript
- Tailwind CSS
- Supabase
- Dexie.js
- Zustand

## Development Priority

Finance module first. Daily Progress and Projects will be implemented in later phases.
